이곳에 등록된 사건들의 연도와 내용을 완벽하게 연상 훈련 하세요.

⚡ 1시간 벼락치기 연대별 치트키

■ 1866년 병·제·병·오 삼총사 테크트리
병인박해 → 제너럴셔먼호 → 병인양요 → 오페르트 도굴(68년) 순서
프랑스 신부 죽여서 미국 배가 평양 왔다가 강화도 전쟁터짐!
■ 1876년 개항기 강화도 트리오
조일수호조규(강화도본조약) → 부록(간행이정) → 무역규칙(양곡 무제한, 무관세)
■ 1882년 격동의 대폭발 라인업
조미수호통상조약 → 임오군란 발생 → 제물포조약(일본군 주둔) → 조청상민수륙무역장정(속국명시) → 척화비 제거
■ 1894년 동학 & 갑오 대혼란 초정밀 서사
고부봉기 → 1차동학 → 전주화약(집강소) → 군국기무처/청일전쟁 → 1차갑오개혁 → 2차동학(남북접) → 우금치 패배 → 2차갑오개혁
■ 1895~1898년 을미에서 독립협회까지
홍범14조 → 시모노세키 → 삼국간섭 → 을미사변 → 을미개혁(단발령) → 아관파천(96) → 독립협회(96) → 대한제국(97) → 만민공동회(98)
■ 1904~1905년 국권침탈 비밀공작
러일전쟁 → 한일의정서 → 보안회 → 1차협약(메가타 고문) → 가쓰라/태프트 → 2차영일동맹 → 포츠머스 → 을사늑약(외교권)
