# 2026 여름방학 완주 플래너

## GitHub와 Vercel에 올리기

1. 이 폴더 안의 파일들을 GitHub 저장소의 최상위에 올립니다.
2. Vercel에서 Add New → Project를 누르고 그 저장소를 선택합니다.
3. Framework Preset은 Other, Build Command는 비워 둔 채 배포합니다.
4. 배포가 끝나면 Vercel 프로젝트의 Domains에서 개인 도메인을 연결합니다.

## 기기에서 처음 열기

- 휴대폰: 인터넷이 있을 때 주소를 한 번 연 뒤 홈 화면에 추가합니다.
- Kindle 4: 인터넷이 있을 때 https://내도메인/?mode=kindle 주소를 한 번 열고 즐겨찾기합니다.
- 오래된 Kindle 브라우저는 오프라인 캐시 지원이 기기 상태에 따라 달라질 수 있습니다. 이 경우에도 하루 숫자 코드는 인터넷 없이 사용할 수 있습니다.

## 오프라인 기기 동기화

1. 기록이 최신인 기기에서 해당 날짜를 엽니다.
2. 화면의 오늘 체크 동기화 숫자 코드를 다른 기기에 입력합니다.
3. 가져오기를 누르면 그 날짜의 10과목 체크 상태만 바뀝니다.
4. 공부시간과 메모까지 옮기려면 저장·설정 화면의 전체 백업 코드를 사용합니다.

두 기기가 서로 직접 통신하는 방식이 아니라 코드를 사람이 옮기는 방식이므로 인터넷, 블루투스, 계정이 필요 없습니다.

## 파일을 수정해 다시 배포할 때

- GitHub 기본 브랜치에 변경을 올리면 연결된 Vercel 프로젝트가 다시 배포됩니다.
- 앱 파일을 크게 수정했다면 sw.js의 CACHE_NAME과 offline.appcache의 첫 주석 버전을 함께 올려 주세요.
